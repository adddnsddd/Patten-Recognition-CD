## 文件夹用途

| 位置 | 内容 |
| --- | --- |
| 文档/课程报告 | 三份最终 Word 报告 |
| 文档/报告模板 | 指定报告模板原件副本 |
| 文档/报告配图 | 已保存的网购报告配图 |
| 三个项目文件夹 | 源码、测试、运行环境、数据与实验结果 |

三个 EXE 保留在本目录，可直接双击运行。人脸识别 EXE 启动后会在旁边建立“人脸识别数据”；迁移历史样本、模型和日志时一并复制。源码命令在对应项目目录执行。各项目 build 中保留验证 JSON 和日志；旧排版校样、重复 EXE、打包临时文件和专用构建环境已清理，需要重新打包时运行对应构建脚本。

扫地项目内的源码与实验数据压缩包是既有归档，本轮没有重新打包。实验原始记录随项目保留，具体算法表现和待测项目以最终报告为准。
